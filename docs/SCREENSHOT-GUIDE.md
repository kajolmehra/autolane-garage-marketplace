# Screenshot guide

Recommended approved visuals: location search, garage detail page, owner listing form, rental checkout summary (rental charge + security deposit), recurring payment status, owner settlement/payment state, service-fee settings, pricing/advertising checkout, and admin listing review. Replace all addresses, map labels, phone numbers, card details, customer/owner names, payment references, subscription IDs, and logos with fictional data. Crop out provider dashboards and never capture real financial records.
